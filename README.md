The program in this repository hands the post's address to make.fun: it copies POST.json, which names the post, into the output directory the house reads.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
